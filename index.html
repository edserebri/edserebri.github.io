Projects

Brown University · Particle Physics

Inference Speedup via Knowledge Distillation

Compressed neural networks for jet tagging in particle physics using knowledge distillation. We achieved over 3× inference speedup and preserved strong classification performance. This work explored how smaller models can reduce computational cost in particle physics data analysis and enable faster processing.

Brown University · Particle Physics

Anomaly Detection in Particle Physics Data

Developed anomaly detection pipelines for high-dimensionals data from particle physics experiments. Beyond detecting anomalous patterns, the project examined robustness, false-positive risk, and model failure modes.

GitHub →

ITMO · Physics-Informed Neural Networks (PINNs)

Reinforcement Learning for PINN Training Dynamics

Developed reinforcement learning-based methods to adaptively control causal weighting in PINN training. Demonstrated on the Allen–Cahn equation that a single adaptive RL-driven training run could match the performance of fixed causal parameters selected through multiple training sweeps.
